# pandas-practices

A collection of pandas practice exercises and notebooks for learning and experimentation.

## Contents
- exercises/ — Jupyter notebooks and scripts with practice problems
- solutions/ — reference solutions (where provided)
- data/ — sample datasets used by the exercises

## Getting started
1. Clone the repository:

```bash
git clone https://github.com/justahmed-dev/pandas-practices.git
cd pandas-practices
```

2. (Recommended) Create and activate a virtual environment:

```bash
python -m venv .venv
source .venv/bin/activate  # macOS / Linux
.venv\Scripts\activate     # Windows
pip install -r requirements.txt
```

3. Open the notebooks in Jupyter or VS Code:

```bash
jupyter lab
```

## Structure
- exercises/: practice notebooks and prompts
- solutions/: example solutions
